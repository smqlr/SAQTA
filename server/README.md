# Сервер SAQTA для Claude

Без сервера приложение работает полностью офлайн: Сактик отвечает из базы знаний, фото распознаёт ИИ в телефоне (MobileNet).
С сервером Сактик отвечает через Claude на любые вопросы, а по фото Claude называет модель, видимые поломки и детали.

## Поиск модели в магазинах

Чтобы точно узнать вещь, Claude не только смотрит на фото, но и ищет её в интернете: в магазинах и каталогах
по всему миру (Kaspi, Technodom, Sulpak, Amazon, AliExpress, eBay, сайты производителей, GSMArena). Это инструмент
веб-поиска на стороне Anthropic (`web_search`): до 4 поисков на фото, местные магазины Актобе впереди.
Ответ — точная модель, год, характеристики, цена «по данным магазинов» и ссылки на страницы, где товар найден.
Сервер оставляет только ссылки, которые реально пришли из поиска. Логика — в `recognize.js`, проверка без сети —
`npm run test:server` в корне репозитория.

- Веб-поиск должен быть включён для организации в Console Anthropic (настройки организации, раздел про веб-поиск).
- Поиск оплачивается отдельно от токенов, по тарифу Anthropic за поиски: https://www.anthropic.com/pricing
- Если Claude откажется отвечать, запрос сам повторит запасная модель Anthropic (`fallbacks: "default"`).

Ключ API хранится только на сервере, в секрете `ANTHROPIC_API_KEY`. В код страницы и в репозиторий его класть нельзя.

## Запуск (Cloudflare Workers, бесплатный тариф)

Нужны: аккаунт Cloudflare и ключ Anthropic API (console.anthropic.com). Ключ и аккаунт создаёт человек, не Claude.

```bash
cd server
```

```bash
npm install
```

```bash
npx wrangler secret put ANTHROPIC_API_KEY
```

```bash
npx wrangler deploy
```

Wrangler напечатает адрес вида `https://saqta-ai.<имя>.workers.dev`. В приложении: «Профиль» → «Сервер ИИ» → вставить адрес.

Необязательно: `ALLOW_ORIGIN` — адрес сайта (например, `https://smqlr.github.io`), чтобы сервер отвечал только ему; `MODEL` — другая модель Claude.

## Стоимость

В бюджете пилота на ИИ заложено 172 000 ₸: 11 000 оценок в хабе и 10 000 в приложении. Одна оценка — около 8 ₸.
Эта оценка посчитана без веб-поиска: поиск по магазинам добавляет к каждому фото плату за поиски и токены результатов.
