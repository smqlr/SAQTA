# Этап 4. Сокращение — «Продли»

Полное описание — в корневом README, раздел «Этап 4. Сокращение». Здесь — как устроены файлы и как обновить цены.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `model/extend-model.mjs` | полные списки цен Kaspi (Актобе) и прайсы мастерских OLX.kz с номерами; расчёт всех цифр этапа |
| `../src/lib/extend.js` | формулы: остаток жизни батареи (закон корня) и «остального» (Вейбулл формы 2), бочка Либиха, закон минимума, W·x/(1+x) |
| `../src/lib/extend-staves.js` | доски бочки для ноутбука, телефона и стиральной машины |
| `../src/screens/extend.js` | экран «Продлить жизнь» |
| `../tests/extend-stage.mjs` | проверка: `npm run extend-stage` |

```bash
node extend/model/extend-model.mjs
```

## Как обновить цены

1. Kaspi: открыть kaspi.kz в браузере и в консоли выполнить запрос
   `/yml/product-view/pl/filters?text=<запрос>&page=0&all=false&fl=true&ui=d&i=-1&c=151010000` (страницы 0 и 1; `c=151010000` — Актобе).
   Отфильтровать по названию и категории, как написано в поле `filter` каждого списка, и заменить `prices` в `model/extend-model.mjs`.
2. Мастерские: прайсы в объявлениях OLX.kz (`WORKSHOPS`) — номер, город, дата.
3. `node extend/model/extend-model.mjs` покажет новые медианы. Перенести их в `src/data.js` (блок `EXTEND`) и цифры — в README.
4. `npm run extend-stage` скажет, если где-то осталось старое число.

## Допущения, которые уточнит пилот

- Порог батареи — 80% ёмкости: на него рассчитаны батареи (чип MacBook хранит DesignCycleCount = 1 000).
- Форма распределения Вейбулла — 2. Каждая сданная вещь приносит в паспорте возраст, и после первых сотен вещей форма станет замером.
- Каждый четвёртый, увидев цену года жизни, выбирает ремонт. Это и есть главный вопрос пилота: экран «Сдать» считает, сколько людей нажали «Продлить».
