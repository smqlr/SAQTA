# ИИ в телефоне: как обучена голова SAQTA

Приложение узнаёт по фото **47 видов техники и «не техника»** без интернета. Раньше вид техники угадывался по
1 000 классам ImageNet (MobileNet v2): у ImageNet нет класса «смартфон», зато есть «iPod», поэтому современные
телефоны часто превращались в «плеер». Теперь у приложения своя обученная голова.

| Движок | Точность на проверочных фото¹ | С двумя кадрами² | Фото каталога |
| --- | --- | --- | --- |
| Было: MobileNet v2 + классы ImageNet | — | — | телефон → «плеер» |
| Запасной: MobileNet v2 + голова SAQTA | 76,8% | 80,4% | 4 из 4 в тесте |
| **Основной: MobileCLIP-S0 + голова SAQTA** | **88,4%** | **90,9%** | **26 из 26** |

¹ 3 569 фото, которых не было в обучении: вещи на «уличных» снимках Open Images — в руках, на столе, среди других вещей.
² Квадрат по центру + всё фото с белыми полями, ответ — среднее.

Проверка через само приложение на снимках, которых модель не видела: телефоны — 38 из 40 первой догадкой,
40 из 40 в двух первых, **ни одного «плеера»**; калькуляторы 10/10, наушники 9/10, планшеты 10/12.

## Данные

- **Open Images V7** (Google): рамки вещей, размеченные людьми, — вырезаем вещь, как её снимает житель
  (`classes.mjs`: класс Open Images → наш вид), и проверенные людьми метки «на фото есть X» для видов без рамок
  (роутер, приставка, утюг, пылесос, колонка, проектор, диск, батарейки, зарядки, кондиционер — `imglabels.mjs`).
- «Не техника» — книги, коробки, рамки, зеркала, сумки, посуда, игрушки и ещё ~60 видов вещей; рамки, внутри
  которых видна техника, выброшены (`select.mjs`).
- Итого 30 194 образца (25 782 фото), по 4 ракурса: кадр как в приложении, вещь целиком с полями
  и два случайных (кадрирование, яркость, контраст, размытие, отражение) — 117 172 ракурса.
- Фото в репозиторий не кладём (5 ГБ). Лицензии: разметка Open Images — CC BY 4.0, фото — CC BY 2.0 (авторы на Flickr).

## Модель

- **MobileCLIP-S0** (Apple, 2024; ONNX от Xenova) — 11,4 млн параметров, эмбеддинг 512. Веса упакованы в float16
  (`pack-onnx.mjs`: граф без весов `src/ai/mclip.onnx` + `src/ai/mclip.f16`, 23 МБ); в браузере разворачиваются
  в float32 — косинус с исходной моделью 0,999. Готовая int8-версия не годится: её эмбеддинги не совпадают с исходными.
- **Голова**: L2-нормировка → стандартизация → 512 ReLU → 48 классов; веса классов 1/√частоты, сглаживание меток 0,1,
  dropout, Adam с косинусным шагом, 40 эпох на видеокарте (tfjs WebGL) — `train.mjs`.
- **Смесь с «нулевым обучением»**: 30% вероятности — косинус эмбеддинга фото с текстовыми описаниями видов
  («a photo of a smartphone», «an MP3 player»… — `text-emb.mjs`, текстовый энкодер MobileCLIP). Помогает на рисунках
  и редких видах. Подбор веса — `ens.mjs`.
- В телефоне всё считает ONNX Runtime Web на WebAssembly, один поток: ~0,2 с на кадр на ноутбуке, 0,5–1 с на телефоне.
  Если WebAssembly не запустился — MobileNet v2 (tfjs) с линейной головой SAQTA.

## Как повторить

Нужны Node 20+, Microsoft Edge (Playwright берёт его как `msedge`) и видеокарта для WebGL/WebGPU.

```bash
cd tools/ai-train/data
```

```bash
bash ../pget.sh https://storage.googleapis.com/openimages/v6/oidv6-train-annotations-bbox.csv train-bbox.csv 2258447590 12
```

Так же — `validation-annotations-bbox.csv`, `test-annotations-bbox.csv`, `class-descriptions-boxable.csv` (как `boxable.csv`)
и проверенные метки (`*-annotations-human-imagelabels.csv`) — адреса в `select.mjs` и `imglabels.mjs`.

```bash
node ../select.mjs
```

Дальше: скачать фото из `download.txt` (S3 `open-images-dataset`, `curl --parallel`), затем

```bash
node ../extract-clip.mjs samples.json imgs oi-clip vision_model.onnx webgpu
```

```bash
DIM=512 NORM=1 APP=app-clip.f32 node ../train.mjs samples.json oi-clip head-clip.json 512 40
```

```bash
node ../export-head.mjs head-clip.json ../../../src/ai/head-clip.json 256 text-emb.json 0.3 30
```

Проверка в приложении: `npm run build`, затем `npm run test:ai` (фото каталога, оба движка).
